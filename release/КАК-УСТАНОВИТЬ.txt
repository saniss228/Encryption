 ENCRYPTION 3.1.0 — защищённый мессенджер с двойным шифрованием
════════════════════════════════════════════════════════════════════════

Что нового в версии 3.1:
  • Админ-панель для аккаунта saniss: управление пользователями (блокировка с
    причиной, выход со всех устройств, админ-права, удаление), группы, файлы,
    журнал безопасности, рассылка объявлений всем клиентам, настройки сервера
    (в том числе закрытая регистрация). Открыть: Настройки → Приложение →
    «Админ-панель». Переписку администратор прочитать НЕ может — на сервере
    хранится только шифротекст.

Что нового в версии 3.0:
  • Файл удаляется с сервера сразу после того, как получатель его скачал.
    В интерфейсе появляется метка «🔒 Только локально / Local only».
  • Четыре языка интерфейса: русский, английский, испанский, немецкий.
  • Из интерфейса убраны технические надписи (адрес сервера, порт, версия).
  • Полная документация API: docs/API.md (REST + WebSocket, примеры curl).

────────────────────────────────────────────────────────────────────────
 1. САЙТ + СЕРВЕР (одним запуском)         release/encryption-3.1.0-server-web.zip
────────────────────────────────────────────────────────────────────────
  На своём компьютере (Windows) — проще всего:
      дважды щёлкните ЗАПУСТИТЬ-МЕССЕНДЖЕР-WINDOWS.cmd
  Скрипт сам поставит окружение, запустит сервер и откроет сайт в браузере.
  Порт по умолчанию 8080; другой порт — аргументом: START-ENCRYPTION-WINDOWS.cmd 9000
  (Linux/macOS: bash tools/start-server.sh)

  На сервере с белым IP:
      sudo bash deploy/install.sh
  Далее сайт открывается по адресу http://45.90.45.92/  (nginx → порт 6000).
  Порт 6000 напрямую в браузере не используется — так его блокируют браузеры.
  Проверка: curl -s http://127.0.0.1:6000/api/v1/health

────────────────────────────────────────────────────────────────────────
 2. ПРИЛОЖЕНИЕ ДЛЯ ПК (Windows)     release/desktop/Encryption-3.1.0-win-x64-portable.exe

────────────────────────────────────────────────────────────────────────
 4. АДМИН-ПАНЕЛЬ (аккаунт saniss)
────────────────────────────────────────────────────────────────────────
  Войдите как saniss (этот логин задан администратором по умолчанию, переменная
  ENC_ADMINS в deploy/encryption.service). Рядом с логином появится значок
  «Администратор», а в Настройках — раздел «Админ-панель».

  Внутри: обзор сервера (пользователи, чаты, файлы, место на диске), список
  пользователей с действиями, группы, файлы, журнал событий, рассылка объявлений
  (баннер видят все клиенты), настройки (регистрация, приветственная заметка).

  Администратор не видит содержимое сообщений и файлов — только метаданные.
