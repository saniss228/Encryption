 ENCRYPTION 3.2.3 — защищённый мессенджер с двойным шифрованием
════════════════════════════════════════════════════════════════════════

Что нового в версии 3.2.3:
  • Адрес для телефона определяется правильно: берётся настоящий Wi-Fi/Ethernet,
    а не Radmin VPN и не «хот-спот» Windows (192.168.137.1). Другие адреса
    показываются отдельным списком. Свой адрес можно задать вручную:
    START-ENCRYPTION-WINDOWS.cmd 6000 8080 192.168.1.50
  • Администратор по умолчанию — saness (было saniss). Прежний логин можно
    сохранить: в службе укажите ENC_ADMINS=saniss,saness

Что нового в версии 3.2.2:
  • Подключение исправлено: сервер слушает порт 6000, как и задумано. Раньше
    скрипты запуска поднимали его на 8080, и приложение не могло подключиться.
  • Сайт на этом компьютере открывается на 8080: браузеры блокируют порт 6000.
    Сервер слушает оба порта одним процессом, данные и аккаунты общие.
  • Если открыть localhost:6000 в браузере, порт меняется на 8080 сам.

Что нового в версии 3.2.1:
  • Запуск на Windows исправлен окончательно: сервер больше не запускается
    «заданием» PowerShell, поэтому строки журнала не превращаются в ошибки
    и сервер не останавливается сразу после старта. Журнал пишется в
    data\server-error.log и виден прямо в окне запуска.

Что нового в версии 3.2:
  • При входе можно выбрать сервер: официальный (из списка) или свой — с вводом
    адреса и проверкой связи. Сменить адрес можно и потом: Настройки → Сервер.
  • Перенос данных на свой сервер: Настройки → Админ-панель → «Данные и перенос»
    → «Скачать копию данных». Один файл с паролем содержит аккаунты, чаты, файлы
    и ключи; на новом сервере: python3 tools/migrate_server.py import файл --force
  • Шифрование не изменилось: содержимое копии остаётся закрытым ключами устройств.

Что нового в версии 3.1:
  • Админ-панель для аккаунта saness: управление пользователями (блокировка с
    причиной, выход со всех устройств, админ-права, удаление), группы, файлы,
    журнал безопасности, рассылка объявлений всем клиентам, настройки сервера
    (в том числе закрытая регистрация). Открыть: Настройки → Приложение →
    «Админ-панель». Переписку администратор прочитать НЕ может — на сервере
    хранится только шифротекст.

Что нового в версии 3.0:
  • Файл удаляется с сервера сразу после того, как получатель его скачал.
    В интерфейсе появляется метка «🔒 Только локально / Local only».
  • Четыре языка интерфейса: русский, английский, испанский, немецкий.
  • Из интерфейса убраны технические надписи (адрес сервера, порт, версия).
  • Полная документация API: docs/API.md (REST + WebSocket, примеры curl).

────────────────────────────────────────────────────────────────────────
 1. САЙТ + СЕРВЕР (одним запуском)         release/encryption-3.2.3-server-web.zip
────────────────────────────────────────────────────────────────────────
  На своём компьютере (Windows) — проще всего:
      дважды щёлкните ЗАПУСТИТЬ-МЕССЕНДЖЕР-WINDOWS.cmd
  Скрипт сам поставит окружение, запустит сервер и откроет сайт в браузере.
  Сервер слушает порт приложений 6000 и порт браузера 8080 (сайт откроется сам).
  Свои порты — аргументами: START-ENCRYPTION-WINDOWS.cmd 6000 9000
  (Linux/macOS: bash tools/start-server.sh 6000 8080)

  На сервере с белым IP:
      sudo bash deploy/install.sh
  Далее сайт открывается по адресу http://45.90.45.92/  (nginx → порт 6000).
  Порт 6000 напрямую в браузере не используется — так его блокируют браузеры.
  Проверка: curl -s http://127.0.0.1:6000/api/v1/health

────────────────────────────────────────────────────────────────────────
 2. ПРИЛОЖЕНИЕ ДЛЯ ПК (Windows)     release/desktop/Encryption-3.2.3-win-x64-portable.exe
    (лежит внутри архива encryption-3.2.3-all.zip)
────────────────────────────────────────────────────────────────────────

────────────────────────────────────────────────────────────────────────
 4. АДМИН-ПАНЕЛЬ (аккаунт saness)
────────────────────────────────────────────────────────────────────────
  Войдите как saness (этот логин задан администратором по умолчанию, переменная
  ENC_ADMINS в deploy/encryption.service). Рядом с логином появится значок
  «Администратор», а в Настройках — раздел «Админ-панель».

  Внутри: обзор сервера (пользователи, чаты, файлы, место на диске), список
  пользователей с действиями, группы, файлы, журнал событий, рассылка объявлений
  (баннер видят все клиенты), настройки (регистрация, приветственная заметка).

  Администратор не видит содержимое сообщений и файлов — только метаданные.
